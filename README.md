# 达人视频协作看板

面向编导、剪辑与中台审核人的独立可运行版本。当前实现以浏览器本地数据作为演示存储，完整覆盖任务状态机、角色待办、团队看板、节点间隔模板、提醒判定和旧数据映射。

## 本地运行

```bash
cd /Users/osaka/Documents/女团/video-collab-board
python3 -m http.server 4173 --directory dist
```

打开 `http://127.0.0.1:4173`。页面右下身份区在演示环境支持切换角色；生产环境应由飞书 SSO 注入身份。

静态入口会为 CSS 和 JavaScript 模块树生成同一个动态版本参数，避免 GitHub Pages 的缓存导致固定链接继续加载旧版本。

## 已实现

- 快速提需使用后台配置的账号下拉，计划发布日期只选择到天，并明确选择“已有素材 / 待拍摄素材”。系统按已确认等级模板自动生成节点时间。每个等级只配置五段相邻节点 SLA：认领后到素材确认、素材确认到剪辑交付、剪辑交付到中台初审、中台初审到编导审核、编导审核到视频发布。节点确认时按实际完成时间启动下一段计时，不再从发布时间统一倒排。
- “我的待办”和九列团队看板支持发布日期筛选：保留今日、未来 3/7 天等快捷选项，也支持在日历中任意点选两个日期，自动按时间先后组成区间；团队看板可与等级、负责人、状态和关键词筛选叠加。年份下拉只展示对应页面任务实际覆盖的年份。
- “我的待办”分为超期、待处理、等待他人三个实时操作模块；下方“全部相关任务”按角色展示完整记录：编导看自己创建的任务，剪辑看自己认领过的任务，中台与管理员看全部任务，日期和状态筛选只作用于该完整记录区。
- 剪辑的“我的待办”增加独立认领池，按认领截止时间排列全部待认领任务，可直接认领。
- “日期汇总”以北京时间周一至周日为一片，连续展示四个自然周；可跳转日期、前后翻周，分别汇总计划拍摄、实际成片交付、仍待认领、计划发布和已发布任务。
- 顶部“操作记录”汇总团队最近 100 条任务事件，可点开对应任务；任务详情可预览已上传的图片、PDF 和小视频附件，交片时也可附上小附件。
- 三个实时操作模块按可用宽度自动调整列数，标题与说明分行展示；任务较多时列表在模块内滚动，模块高度不随任务数无限增长。
- 专用状态动作：认领、拍摄与素材交接、提交成片、初审、终审、修改和发布。待拍摄任务在完成拍摄时一次确认素材给予方式并直接进入剪辑，不再拆成两个连续状态。
- 是否进入中台初审由等级模板独立配置；已有素材任务跳过拍摄，只需确认素材给予方式。
- 管理员可新增任意等级、编辑名称和颜色、选择是否初审，并停用不再使用的等级；历史任务不受停用影响。
- 管理员可维护账号 / 达人库和素材给予方式；确认素材时必选给予方式，并可补充小附件或文字备注。
- 管理员可手动维护平台身份的姓名、角色、启用状态和页面权限，并在“手动身份 / 飞书 SSO”两种识别模式之间切换；角色控制流程操作权，页面权限控制导航入口。
- 成片版本保留、审核意见时间轴、暂停、恢复、取消、改期和转交。
- 审核弹窗打开即展示可选备注，填写后直接点击“通过审核”或“退回修改”完成处理，不再二次确认。
- 临期、到期、超期升级、每日汇总判定与提醒去重。
- 历史已发布任务只读归档，进行中任务按现有字段映射。
- 电脑完整操作和手机快捷操作布局。

## 生产接入边界

当前工作区没有原生产看板源码、数据库结构或飞书应用凭据，因此以下适配器已留出接口，但未伪造线上连接：

1. **飞书身份**：服务端完成 OAuth/SSO 后，在页面加载前注入：

   ```js
   window.__VIDEO_BOARD_CONFIG__ = {
     currentUser: { id: "ou_xxx", name: "用户姓名", role: "director" }
   };
   ```

2. **提醒服务**：配置 `reminderEndpoint`，接收 `{ reminders: ReminderRecord[] }`。服务端负责飞书卡片消息、私聊/群聊路由和发送结果回写。
3. **持久化与并发**：生产环境必须把 `localStorage` 替换为服务端数据库；认领接口使用事务或版本号条件更新，保证多人认领只有一人成功。
4. **附件**：演示环境仅在浏览器本地保存 1MB 以内的小附件；生产环境应接飞书云盘或对象存储，不在浏览器中直接保存大视频。

## 推荐服务端动作接口

不要提供通用的 `PATCH status`。按业务动作提供幂等接口：

- `POST /api/tasks`
- `POST /api/tasks/:id/claim`
- `POST /api/tasks/:id/shoot-complete`
- `POST /api/tasks/:id/material-ready`
- `POST /api/tasks/:id/cuts`
- `POST /api/tasks/:id/reviews`
- `POST /api/tasks/:id/publish`
- `POST /api/tasks/:id/pause|resume|cancel|reschedule|transfer`

每次请求携带任务版本号，成功时在同一事务内写入任务状态、节点完成时间与 `TaskEvent`。
